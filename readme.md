# Freight Rate ML Assessment - Spotter

Production-grade machine learning solution for the **Spotter Freight Rate Prediction Assessment**. This project models freight spot rates across diverse freight lanes, equipment types, and macroeconomic conditions, accurately forecasting 12,000 future loads in November–December 2025.

---

## 📌 Executive Summary & Architecture

- **Task:** Predict `posted_rate` ($) across 12,000 out-of-time validation loads (`validation.csv`) and evaluate fixed-lane December daily dynamics (`december-chart-inputs.csv`).
- **Validation Strategy:** Strict **Out-Of-Time (OOT)** holdout split (Train: Jan 1 – Aug 31, 2025 | Val: Sep 1 – Oct 31, 2025) to prevent temporal data leakage and mimic the 2-month lookahead test environment.
- **Champion Model:** Weighted ensemble blend of **LightGBM (55%)** and **CatBoost (45%)** optimizing L1/MAE loss with domain-engineered geospatial, calendar, and freight market signals.
- **Out-of-Time Performance:** **$112.39 MAE** | **4.70% WAPE** (a 54.4% error reduction over the domain baseline).
- **Compliance:** 100% verified with Spotter's official `score.py` validator.

## 🚀 Quickstart & Setup

### 1. Environment Setup

```bash
# Clone the repository
git clone <your-repo-url>
cd spotter-ml-assessment

# Create and activate a virtual environment
python -m venv venv
# On Windows:
.\venv\Scripts\activate
# On Linux/macOS:
source venv/bin/activate

# Install dependencies
python -m pip install -r requirements.txt
```

### 2. Run the Full End-to-End Pipeline

Run the automated pipeline to execute OOT validation, train the champion ensemble on the full 48,000 development loads, generate predictions, and run `score.py`:

```bash
python run_pipeline.py
```

### 3. Verify with the Official Scorer

You can independently verify the submission files using Spotter's `score.py`:

```bash
python score.py --predictions validation_predictions.csv --december-predictions data/december-chart-inputs.csv
```

**Scorer Output:**
```
Validated 12,000 final predictions.
Validated 31 fixed December predictions.
Created chart: scorer_results/candidate_december.png
Final validation metrics are calculated by Spotter after submission.
```

## 📊 Benchmark Results (Out-Of-Time Validation)

Evaluated on the strict September 1 – October 31, 2025 holdout split (9,523 loads):

| Model Architecture | MAE ($) | RMSE ($) | Median AE ($) | WAPE (%) | MAPE (%) |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **Domain Baseline** (`distance * quote_signal` + equipment ratios) | $246.29 | $710.65 | $65.32 | 10.29% | 12.10% |
| **LightGBM Regressor** (L1 / MAE Objective) | $111.71 | $635.18 | $36.03 | 4.67% | 4.75% |
| **CatBoost Regressor** (MAE Objective) | $117.24 | $636.72 | $42.48 | 4.90% | 5.16% |
| **Champion Ensemble** (55% LightGBM + 45% CatBoost) | **$112.39** | **$635.54** | **$37.95** | **4.70%** | **4.82%** |

*WAPE (Weighted Absolute Percentage Error): $\frac{\sum |y - \hat{y}|}{\sum y} \times 100\%$ — standard metric for freight pricing.*

## 📈 December 2025 Fixed-Lane Stress Test

![Candidate December Predicted Load Rate](report/candidate_december.png)

### Key Economic Dynamics Observed:
1. **Realistic Rate Level:** Rates consistently track between **$814 and $845** (averaging **~$2.30/mile** for the 360-mile Lexington $\to$ Fort Wayne Dry Van haul), matching spot market expectations.
2. **Weekly Shipping Rhythm:** Strong midweek volume surges (peaking Wednesdays/Thursdays at $838–$843) followed by weekend drops (bottoming at $820–$827) as shippers close dock facilities.
3. **Holiday Capacity Tightness:** Upward trend heading into the Christmas shipping crunch ($844.25 on Dec 25) followed by a year-end surge ($845.15 on Dec 31).
